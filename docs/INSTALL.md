# 安装和连接

[中文](INSTALL.md) | [English](INSTALL.en.md)

**Windows x64 安装包：`0.1.0-preview.1`。** 在[Releases](https://github.com/seagull226/surelive-local-assistant/releases/tag/v0.1.0-preview.1)下载 `.exe`，兼容范围及验证结果以该版本说明为准。需要配套的隔离影院；这不是给任意旧版插件增加入口的更新。GitHub 自动生成的 “Source code” ZIP 是源码，不能双击安装。

## 使用前确认

- Windows x64。当前实测开发机结果不代表所有 Windows 版本均已验证；不支持 macOS、Linux 或 Windows ARM 安装包。
- 需要配套隔离影院。正式插件尚未开放的 ASR 功能不会因安装助手自动出现。当前影院仍负责播放、字幕显示及翻译；助手不是独立视频播放器。
- CPU 可以运行，不强制要求独立显卡。当前 GPU 路线为 NVIDIA CUDA；AMD/Intel 显卡走 CPU。含完整 GPU 运行库的候选无需额外安装 CUDA 工具包，但仍需要兼容显卡驱动。
- 安装包不包含模型。模型和媒体解码临时文件需要额外空间；长片资源占用与时长有关，没有 90 分钟限制不等于无限资源。

## 安装和首次使用

1. 在本仓库 Releases 下载 `SureLive-Local-Assistant-0.1.0-preview.1-win-x64.exe`，并核对同版本 `SHA256SUMS.txt`。不要把历史隔离 EXE 当作本版本。
2. 安装到当前 Windows 用户。当前脚本不要求管理员权限，安装时注册 Chrome/Edge 的本机连接入口。安装器现为中文，助手窗口可切换中文/English。
3. 打开“本机字幕助手”。选择 Small 或 Large-v3，点击“下载 / 继续准备”，或用“使用已有模型…”导入完整的对应模型目录。
4. 在配套影院加载本地视频，选择“Whisper · 本机助手”，点击“连接助手”或“生成字幕”。首次连接无需输入连接码。
5. 视频原语言应按视频实际对白选择，或选自动检测；它不由学习语言强制决定。翻译目标由插件的“我的母语”决定。识别结果仍需核对。

下载后可用 PowerShell 核对文件哈希：

```powershell
Get-FileHash -Algorithm SHA256 -LiteralPath .\SureLive-Local-Assistant-0.1.0-preview.1-win-x64.exe
```

目前构建未签名。Windows 可能提示未知发布者或阻止运行，企业策略也可能禁止继续；哈希校验不能替代数字签名。不要关闭安全防护来完成安装，也不承诺签名后一定没有提示。见 [Microsoft 说明](https://learn.microsoft.com/en-us/windows/apps/package-and-deploy/smartscreen-reputation)。

## 模型、下载和语言

| 模型 | 完整固定文件总大小（不含缓存/临时文件） | 识别语言 | 选择参考 |
| --- | --- | --- | --- |
| Small 多语言版 | 约 486 MB（464 MiB） | 99 种 | 下载较小，优先用于 CPU 或快速试用 |
| Large-v3 | 约 3.09 GB（2.88 GiB） | 100 种 | 资源占用较高，有显卡时可比较效果 |

两者均支持中文、英语、日语、韩语、法语、德语、西语等。Small 不是仅英语的 `small.en`；语言数量不代表各语言准确率相同。精确语言代码和固定文件清单见[模型配置](../resources/models.json)。

下载源可选 Hugging Face 官方源、HF-Mirror 国内第三方镜像或自动（官方失败后尝试镜像）。所有来源都校验固定版本的 SHA-256，不承诺任一网络环境始终可下载；镜像不是官方托管，也不接收用户账号或媒体。下载中断可继续，网络不通时可从另一台电脑取得匹配版本的完整文件夹后导入。

导入必须包含 `model.bin` 和该模型清单要求的配置、分词器及词表；仅有 `.pt`、ONNX 或单个 `model.bin` 不行。导入会校验并复制到当前模型目录；“模型存储位置”只改变以后使用的位置，不自动搬迁已有模型。

## 运行方式

`--installer` 生成按用户安装的 EXE。用户安装后在当前用户注册 Chrome/Edge Native Host；没有开机自启。卸载只删除安装文件和属于该目录的注册，保留模型及额外用户文件。

影院点击连接/准备/生成才启动助手，打开影院或切换引擎本身不启动。管理窗口可收进托盘，从托盘退出才完全退出管理窗；断开影院会清理对应会话及其子进程。

SenseVoice 在浏览器中运行，主要支持中、英、粤、日、韩；它的模型导入和浏览器缓存由插件管理，与本助手的 Whisper 模型分开。

## 隐私、退出和卸载

识别音频和字幕在本机处理。准备模型时会连接所选下载站点；字幕翻译可能使用插件配置的网络服务，不能把整个插件描述为完全离线。

识别期间保持影院连接。管理窗口关闭按钮会收进右下角托盘，可从托盘重新打开或退出；运行任务时退出会提示并停止相关工作。没有 Windows 开机自启。

从 Windows 已安装应用中卸载。卸载保留模型和额外用户文件，需删除时由用户确认实际模型路径后自行处理。本版本沿用隔离安装身份，不宜在正在识别时覆盖安装。具体安装/卸载测试范围见该 Release 的说明。

## 常见问题

| 现象 | 检查 |
| --- | --- |
| 连接失败 | 配套扩展 ID、Windows 用户、安装目录和系统策略 |
| GPU 不可用 | 驱动及运行库；可以用 CPU。AMD/Intel 显卡不通过 CUDA 路线加速 |
| 下载失败 | 查看来源与错误，继续下载或导入完整模型目录 |
| 长片失败 | 检查临时磁盘、音轨与资源；没有固定时长限制不表示无限资源 |

不要通过关闭防火墙、杀毒或企业策略完成验证。
