# 安装和连接

当前提供源码，没有正式安装器下载。自行构建的结果默认仍是隔离试用版本。

## 保持的身份

- Native Host：`com.surelive.asr.preview`
- 扩展 ID：`pigcndembijihpdlkdpmopjddomgjogc`
- 协议版本：`1`
- 数据目录：`%LOCALAPPDATA%/SureLiveASRPreview`

仓库改名不改变连接身份。其他扩展 ID 不能直接连接；未来切换商店扩展时应统一核对 `host.py`、生成的 manifest 和 HTTP Origin 校验，不开放任意来源。

## 运行方式

`--installer` 生成按用户安装的 EXE。用户安装后在当前用户注册 Chrome/Edge Native Host；没有开机自启。卸载只删除安装文件和属于该目录的注册，保留模型及额外用户文件。

影院点击连接/准备/生成才启动助手，打开影院或切换引擎本身不启动。管理窗口可收进托盘，从托盘退出才完全退出管理窗；断开影院会清理对应会话及其子进程。

首次使用下载或导入完整匹配模型目录；Small 是多语言模型，不是 small.en。单个 `model.bin` 不足够，助手核验完整清单。视频原语言在影院选择，译文目标由插件的母语设置决定。

| 现象 | 检查 |
| --- | --- |
| 连接失败 | 配套扩展 ID、Windows 用户、安装目录和系统策略 |
| GPU 不可用 | 驱动及运行库；可以用 CPU。AMD/Intel 显卡不通过 CUDA 路线加速 |
| 下载失败 | 查看来源与错误，继续下载或导入完整模型目录 |
| 长片失败 | 检查临时磁盘、音轨与资源；没有固定时长限制不表示无限资源 |

不要通过关闭防火墙、杀毒或企业策略完成验证。
